# 📊 Student Enrollment and Fee Analytics Dashboard Using PowerBI

An interactive Power BI dashboard designed to analyze student enrollment trends, course popularity, demographic distributions, and total fee generation[cite: 1].

---

## 🚀 Overview

This project provides data-driven insights into student registrations and financial performance across various creative and technical courses. It highlights key performance indicators (KPIs) like total fee revenue, total student count, enrollments by month, age demographics, and course-wise performance[cite: 1].

---

## 📈 Key Dashboard Metrics & Visualizations

* **Total Fee Revenue:** Tracks the overall financial generation, standing at **6,877.50K ₹**[cite: 1].
* **Total Student Count:** Displays the active student population base of **772** students[cite: 1].
* **Global Filters:** Interactive slicers for **Date of Join (Year)**, **City**, and **Course** to dynamically filter the report[cite: 1].
* **Sum of Fees by Course:** Horizontal bar chart highlighting revenue contribution per course, led by *Davinci Resolve* (1,400.00K ₹) and *Adobe After Effects* (1,188.00K ₹)[cite: 1].
* **Gauge / Count Visual:** Displays primary enrollment status against benchmarks (e.g., highlighting 504 out of 772 students)[cite: 1].
* **Count of Course by Month Number:** Column chart showing seasonal enrollment patterns across months 1 through 12, with a peak of 116 enrollments in month 11[cite: 1].
* **Count of Course by Age Group:** Donut chart breaking down student demographics across age brackets:
  * **19 to 26:** 251 students (32.51%)[cite: 1]
  * **33 to 35:** 226 students (29.27%)[cite: 1]
  * **27 to 30:** 219 students (28.37%)[cite: 1]
  * **Other:** 76 students (9.84%)[cite: 1]
