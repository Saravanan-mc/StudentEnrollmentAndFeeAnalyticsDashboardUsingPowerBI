# 📊 Student Enrollment and Fee Analytics Dashboard Using Power BI

## 🚀 About the Project

An interactive Power BI dashboard designed to analyze student enrollment, course popularity, student demographics, and fee revenue. It transforms student data into meaningful visual insights to support better decision-making.

## 🎯 Key Features

- 💰 **Total Fee Revenue:** Displays total fee revenue of ₹68,77,500.
- 👨‍🎓 **Total Students:** Tracks 772 student records.
- 📚 **Course-Wise Revenue:** Compares fee revenue generated by different courses.
- 📅 **Monthly Enrollment:** Analyzes student enrollment trends across 12 months.
- 👥 **Age Group Analysis:** Visualizes student distribution by age group.
- 🌍 **Interactive Filters:** Filters data by joining year, city, and course.
- 📊 **Visual Analytics:** Presents data through interactive charts, cards, gauges, and graphs.

## 📈 Key Insights

- 💵 Total fee revenue: ₹68,77,500.
- 🎓 Total student count: 772.
- 🎬 DaVinci Resolve generates the highest course revenue at ₹14,00,000.
- 🎨 Adobe After Effects generates ₹11,88,000 in revenue.
- 📅 Month 11 records the highest enrollment, with 116 students.
- 👥 The 19–26 age group contains 251 students (32.51%).
